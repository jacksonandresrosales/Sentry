# Instrucciones de contribución

Este repositorio pertenece a `jacksonandresrosales`. Antes de cada commit, verifica que `git remote get-url origin` apunte a `jacksonandresrosales/Sentry`, que `git config user.name` y `git config user.email` identifiquen a Jackson y que la credencial GitHub usada para publicar pertenezca a `jacksonandresrosales` (verifica la identidad autenticada con `gh api user --jq .login`). Si cualquiera de estas comprobaciones no coincide, corrígela en el ámbito de este repositorio antes de crear el commit o enviar cambios. Nunca publiques Sentry con otra cuenta.
